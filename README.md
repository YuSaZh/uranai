# Uranai — Tarot Divination Web App

一款面向移动端优化、拥有沉浸式交互动画与仪式感视觉设计的塔罗牌占卜 Web App。

## 核心目标功能

- **卡面展示**：78 张塔罗牌鉴赏、正逆位牌义与精细视觉呈现
- **每日占卜**：每日一牌快速抽取与指引
- **自定义问题占卜**：输入占卜问题 → 选择占卜类型（爱情 / 事业 / 财运 / 综合等） → 选择不同张数牌阵抽卡（单张 / 三张时间流 / 五张 / 凯尔特十字等）
- **历史记录**：自动保存过往占卜记录、所抽牌面与问题回顾
- **自定义桌布（背景）**：多款不同质感与氛围的占卜桌布自由切换
- **移动端优先体验**：触控手势洗牌、扇形抽牌、3D 翻牌与光效动画
